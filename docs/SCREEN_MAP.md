# Screen Map

## Desktop Navigation

Today · Bookings · Academy · Customers · Payments · Invoices · Reports · Club · Staff · Settings

## Mobile Navigation (bottom bar)

Today · Bookings · **Scan** · Academy · More

`Scan` is given a prominent, thumb-reachable center position — it's a high-frequency action for reception/gate staff.
